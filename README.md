# Nexora IT Services Website

Deployable React + Vite prototype.

## Local development
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.

## Production build
Run `npm run build`. The deployable output is generated in `dist/`.

## Cloudflare Pages
Connect the Git repository and use:
- Build command: `npm run build`
- Output directory: `dist`

## Netlify
Use the same build command and output directory.

Replace placeholder company name, address, phone, email and partner information before public launch. The contact form is currently UI-only and requires a backend/form service to send messages.
